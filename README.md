# Script-GEE-Ketinggian-Bangunan-Kota-Balikpapan-Tahun-2023
Repositori ini berisi skrip Google Earth Engine (GEE) untuk mengekstraksi dan memvisualisasikan data ketinggian bangunan di Kota Balikpapan menggunakan dataset tahun 2023. Skrip ini memproses citra penginderaan jauh guna menghasilkan estimasi elevasi bangunan, mendukung analisis tata ruang, dan pemetaan infrastruktur perkotaan.
